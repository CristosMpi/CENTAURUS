# Security policy

CENTAURUS V4 — ABYSSAL is the supported security entrypoint. Historical V1/V2/V3 and audio-model applications are retained for reference and migration, without V4's request boundary. Do not expose those listeners in a V4 deployment.

For sensitive vulnerability reports, use this repository's private GitHub vulnerability reporting feature if enabled. If it is unavailable, contact the maintainer privately before sharing exploit details, device keys, credentials, telemetry, or site locations in a public issue.

See [the V4 trust model](docs/v4_security.md) and [deployment and recovery procedures](docs/v4_operations.md). No system is guaranteed invulnerable; automated tests and advisory scans cover specific properties and published vulnerabilities rather than establishing certification.
